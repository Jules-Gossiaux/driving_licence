Lorsque la remorque dépasse 750 kg, le permis B ne suffit plus automatiquement.
Deux solutions prennent le relais selon la MMA de l'ensemble : le code 96 et le
permis BE.

## Le code 96

Le **code 96** concerne les ensembles dont la remorque dépasse 750 kg et dont
la MMA se situe **au-dessus de 3 500 kg, sans dépasser 4 250 kg**.

Il s'ajoute au permis B. Il ne crée pas une nouvelle catégorie de permis : il
autorise son titulaire à conduire cette catégorie d'ensemble, dans la limite de
4 250 kg de MMA.

Un ensemble de 4 000 kg avec une remorque de plus de 750 kg relève donc du
code 96, pas du permis B seul.

## Le permis BE

Le **permis BE** prend le relais lorsque la MMA de l'ensemble dépasse
**4 250 kg**, sans dépasser **7 000 kg**, toujours avec une remorque de plus de
750 kg.

Contrairement au code 96, le permis BE est une **catégorie distincte**. Il ne
s'agit pas d'une simple mention ajoutée au permis B.

Un ensemble de 5 000 kg avec une remorque de plus de 750 kg nécessite donc le
permis BE.

## Les seuils exacts

| MMA de l'ensemble        | Solution                       |
| ------------------------ | ------------------------------ |
| Jusqu'à 3 500 kg         | Permis B                       |
| Plus de 3 500 à 4 250 kg | Permis B + code 96             |
| Plus de 4 250 à 7 000 kg | Permis BE                      |
| Plus de 7 000 kg         | Hors du champ de ces solutions |

Les bornes sont inclusives dans le cas inférieur : 3 500 kg reste en B,
4 250 kg reste en code 96 et 7 000 kg reste en BE.

> **Piège d'examen** — Le code 96 et le permis BE ne sont pas interchangeables.
> Le code 96 s'ajoute au permis B ; le permis BE est une catégorie à part.

## À retenir

Remorque de plus de 750 kg : jusqu'à 3 500 kg d'ensemble, le permis B suffit ;
de plus de 3 500 à 4 250 kg, il faut le code 96 ; de plus de 4 250 à 7 000 kg, le
permis BE.
