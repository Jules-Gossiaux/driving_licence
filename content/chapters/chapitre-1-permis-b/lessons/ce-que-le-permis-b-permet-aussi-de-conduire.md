Le permis B ne se limite pas aux voitures. Il ouvre aussi l'accès à deux
catégories de deux-roues, avec des conditions différentes selon le véhicule.

## Les cyclomoteurs et speed pedelecs

La catégorie **AM** est ajoutée automatiquement au permis B. Elle couvre les
cyclomoteurs, mais aussi les **speed pedelecs**, ces vélos électriques rapides
assimilés à des cyclomoteurs.

Pour un speed pedelec, un **permis B définitif** est nécessaire. Un permis
provisoire ne suffit pas. Cette règle est distincte de la formation A1 décrite
ci-dessous : elle s'applique même sans code 372.

## La moto légère avec le code 372

Une **moto légère de catégorie A1** peut être conduite avec un permis B, mais
seulement si trois conditions sont réunies :

- le permis B est détenu depuis **au moins 2 ans** ;
- une formation pratique de **4 heures** a été suivie dans une école agréée ;
- le **code 372** a été ajouté au permis.

La moto doit elle-même rester dans les limites de la catégorie A1 :
**125 cm³ maximum**, **11 kW maximum** et un rapport puissance/poids qui ne
dépasse pas **0,1 kW/kg**.

## Les limites de ces autorisations

Le code 372 n'est pas un permis A1 complet. Il est valable **uniquement en
Belgique** : si vous roulez dans un autre pays, un permis A1 de plein droit peut
être exigé.

Ces autorisations ne modifient pas les plafonds du permis B pour les voitures
et les remorques. Conduire un cyclomoteur ou une 125 ne permet pas de tracter
une remorque plus lourde.

> **Piège d'examen** — Un permis B récent ne suffit pas pour une 125 : il faut
> attendre 2 ans, suivre 4 heures de formation et obtenir le code 372.

## À retenir

Le permis B inclut la catégorie AM. Pour une moto légère A1 en Belgique, il faut
un permis B de 2 ans minimum, 4 heures de formation et le code 372. Le speed
pedelec, lui, exige un permis B définitif.
