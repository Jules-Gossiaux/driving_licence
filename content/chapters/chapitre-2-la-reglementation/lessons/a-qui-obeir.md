## Les agents qualifiés

Certaines personnes peuvent vous donner des **injonctions**, c'est-à-dire des
ordres que tout usager doit exécuter. Ce sont les agents qualifiés :

- les policiers **locaux**, **fédéraux** ou encore **militaires** ;
- les **douaniers** ;
- les **agents des sociétés de transport en commun** ;
- les **pompiers** et les membres de la **Protection civile**, avant l'arrivée de
  la police sur le lieu de l'intervention.

## Comment un agent donne-t-il un ordre ?

Une injonction peut prendre plusieurs formes :

- des **gestes** : ralentir, accélérer, se rabattre sur une autre bande ;
- la **parole** ;
- tout autre moyen de communication : haut-parleur, panneaux lumineux, signal
  STOP.

Si l'agent est en civil, il doit d'abord vous montrer sa **carte de
légitimation** pour que son injonction soit valable.

## Trois positions, trois couleurs

La position de l'agent remplace les feux de circulation :

| Position de l'agent | Équivalent | Ce que vous devez faire                                                                                                          |
| ------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| De profil           | Feu vert   | Vous pouvez vous engager : tout droit, à gauche ou à droite.                                                                     |
| Bras levé           | Feu orange | Arrêt pour tous les usagers, dans toutes les directions. N'entrez pas dans le carrefour ; dégagez-le si vous y êtes déjà engagé. |
| De face ou de dos   | Feu rouge  | Arrêt obligatoire.                                                                                                               |

![Les positions de l'agent et leurs équivalents lumineux](/media/ch02/agent-positions.svg)

## Le piège du bras gauche

Un agent vous fait face et tend son **bras gauche** : vous ne pouvez pas vous
engager, **même pour tourner à droite**. Un agent de face ou de dos impose
toujours l'arrêt, sans exception pour un virage à droite.

La nuit, la même logique s'applique : si un agent face à vous balance une torche
électrique à **embout rouge éclairé**, vous devez vous arrêter.

> **Piège d'examen** — « Agent de face ou de dos » ne signifie pas seulement
> « agent qui regarde ailleurs ». Cette position correspond au feu rouge et
> impose l'arrêt, y compris pour un virage à droite.

## À retenir

Agent **de profil** = feu vert. Agent **au bras levé** = feu orange. Agent **de
face ou de dos** = feu rouge. Une injonction d'agent prime sur les feux et la
signalisation.
